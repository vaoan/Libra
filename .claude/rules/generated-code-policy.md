# Generated code

Loaded when `packages/api` or the Orval config is read. Each line is the rule; the link is the full text.

- **A file is generated if its path has `generated` or `__generated__`, its header says "auto-generated", "generated by" or "DO NOT EDIT", or a generator produces it**, such as `packages/api/src/supabase/types.ts` from `pnpm codegen:supabase`. → `docs/lessons/generated-code-policy.md` (How to Identify Generated Files)
- **Never hand-edit one; change the source and rerun `pnpm codegen` or `pnpm codegen:supabase`**, because the next run overwrites the edit. → `docs/lessons/architecture.md` (Generated Code (Orval))
- **In a review, report only consistency: types, names, signature or shape mismatches that break callers.** Severity info or warning, naming the generator as the fix path. No refactors, DRY, performance or style findings. → `docs/lessons/generated-code-policy.md` (Reporting Guidance)
